## Features
 
- Light and dark theme
- Animated hero with 3D tilt effects
- Project showcase with filters and detail view
- Certificates gallery with full-screen viewer
- **Myra AI** — portfolio assistant (English + Hinglish, voice supported)
- Contact and feedback forms with email delivery
- Fully responsive on mobile, tablet and desktop
